# Neutrality And Consent

This project supports Wikipedia-facing research. That means:

- every factual claim should be backed by public, reliable sources
- insider memory may guide research, but should not be treated as a source
- the repository should not imply endorsement by named individuals
- recipients should be invited to opt in, not enrolled by default
- direct contact data should remain outside the public tree

Company employees, former employees, competitors, and legal stakeholders may all have useful context. None of that changes the requirement to keep the work neutral, source-driven, and public-interest oriented.

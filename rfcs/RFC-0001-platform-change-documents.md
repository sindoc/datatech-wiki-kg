# RFC-0001: Request For Change Documents

Status: draft
Date: 2026-03-27

Request for Change documents are the structural-change companions to ADRs.

- ADRs capture accepted architectural decisions.
- RFCs capture proposed structural changes before acceptance.
- Both should be available as Markdown and XML so they can flow through Logseq, SilkPage, and Collibra-oriented exchange patterns.
